# Worst Fix Ever: Funniest Commit Message

One commit message for a bug fix that made everything worse:

> fix: crash is gone because the app no longer starts

The fix technically worked — the crash is gone, because the whole app no longer starts. The repair cured the symptom by killing the patient.

`main.py` writes the entry to `/output/entry.txt`. Run it with `python3 main.py`.
